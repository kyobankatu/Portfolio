# Portfolio

かつもんのポートフォリオサイト。

## Stack

- **Next.js 15** (App Router) — static site generation
- **React 19**
- **CSS Modules** + global CSS

## Development

```bash
npm install
npm run dev      # http://localhost:3000
```

## Build

```bash
npm run build
npm run start    # preview production build
```
